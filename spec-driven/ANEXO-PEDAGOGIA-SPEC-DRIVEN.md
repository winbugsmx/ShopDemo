## 1. Objetivos de aprendizaje

Al completar esta etapa, el alumno será capaz de:

1. Trabajar con **especificaciones versionadas** como fuente de verdad para agentes IA.
2. Activar **Cursor** con rules, skills y commands del curso.
3. Activar **Claude Code** con `CLAUDE.md` y carpeta `.claude/`.
4. Separar commands de **despliegue Azure** y **AWS**.
5. Configurar **MCP** para local, Azure y AWS sin exponer secretos.
